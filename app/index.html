EdgeBench Predictor

Hệ thống dự đoán hiệu năng mô hình Deep Learning trên hai nền tảng NVIDIA RTX 3080 (cloud) và Jetson Nano (edge). Sử dụng mô hình CatBoost được huấn luyện từ dữ liệu benchmark thực tế để dự đoán 4 chỉ số hiệu năng trong vài giây.

⚡

Dự đoán tức thì — Server RTX 3080

Nhập tên mô hình timm và nhận kết quả dự đoán accuracy, latency, throughput, energy consumption trên NVIDIA RTX 3080 trong chưa đầy 1 giây.

🔌

Benchmark thực tế — Edge Jetson Nano

Kết nối SSH tới thiết bị Jetson Nano, chạy benchmark trực tiếp và thu thập số liệu thực tế. Sau đó so sánh và đánh giá với dự đoán từ CatBoost.

📂

Import file mô hình (.pth, .safetensors…)

Upload file mô hình PyTorch trực tiếp. Hệ thống đọc nội dung, trích xuất tham số, tự động khớp với dataset để đưa ra dự đoán chính xác.

📊

So sánh đa tiêu chí

Đánh giá tổng hợp theo Accuracy, Latency, Throughput, Energy với hai chế độ: Tốt nhất đơn tiêu chí và Đa tiêu chí có trọng số.

Hướng dẫn sử dụng

Hướng dẫn từng bước để dự đoán và benchmark hiệu năng mô hình Deep Learning trên hai nền tảng.

SERVER · RTX 3080 — Dự đoán nhanh
1

Chuyển sang tab Server · RTX 3080

Nhấn nút Server · RTX 3080 ở thanh điều hướng bên trái để vào trang dự đoán.

2

Nhập tên mô hình hoặc import file

  • Nhập tên: Gõ tên model theo chuẩn timm (vd: resnet50, efficientnet_b0, vit_tiny_patch16_224). Dùng nút "Tra cứu 797 tên" để tìm kiếm.
  • Import file: Nhấn "Import file mô hình" và chọn file .pth, .pt, .safetensors, .bin hoặc .ckpt. Hệ thống tự đọc và phân tích.
3

Nhấn "Dự đoán hiệu năng"

Kết quả hiển thị ngay: Accuracy (độ chính xác ImageNet), Latency (ms/ảnh), Throughput (img/s), Energy (mJ/ảnh).

EDGE · JETSON NANO — Benchmark thực tế
1

Chuyển sang tab Edge · Jetson Nano

Nhấn Edge · Jetson Nano ở thanh điều hướng trái. Chọn tab "Thu thập (SSH → flops_csv2.py)".

2

Nhập thông tin kết nối SSH

  • Host / địa chỉ IP của Jetson Nano (vd: 192.168.0.119)
  • Username và Password
  • Tên mô hình cần benchmark (vd: resnet18)
3

Nhấn "Chạy benchmark" và chờ kết quả

Terminal hiển thị output realtime qua WebSocket. Sau khi hoàn tất, chuyển sang tab "Dự đoán + đánh giá" để xem kết quả so sánh.

4

Đánh giá và so sánh

Nhập tên model trong tab Dự đoán để xem kết quả CatBoost, so sánh với số liệu benchmark thực tế, đánh giá theo đơn tiêu chí hoặc đa tiêu chí.
